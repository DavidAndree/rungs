          How Rungs uses the graph

          1

          Every job is a node

          910 O*NET occupations connect to 68 skills and knowledge areas (NEEDS, with importance and level) and 176 in-demand tools (USES).

          2

          Moves are edges

          15,486 STEP edges link jobs with overlapping skill profiles, never more than one training level up, each carrying the skill gap.

          3

          Routes are paths

          SHORTEST 16 (me)-[:STEP]->{1,6}(goal) finds stepping-stone careers (loops filtered out), ranked by the total skills you'd need to build.

          4

          It's personal

          Mark skills you already have and every gap is recomputed live in Cypher: no server, all inside Relate running in this tab.
